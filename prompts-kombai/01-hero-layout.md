# Prompt 1 para Kombai — Hero + Layout Base

## Qué necesito

Crea la página principal (landing page) de un proyecto llamado **"THE GOLDEN VOTE"**.

## De qué trata

Es una web donde la gente vota por el mejor futbolista de la historia. Cada voto cuesta $1 USD. Los votos se cuentan en tiempo real.

## Qué debe tener esta primera pantalla

### Header / Navegación
- Logo con el texto "THE GOLDEN VOTE" en tipografía elegante y dorada
- Menú con links: "La Historia" | "Votar" | "Ranking en Vivo"
- Un botón destacado que diga "VOTA AHORA — $1"

### Hero (la sección grande de bienvenida)
- Un título grande e impactante. Algo como: **"EL DEBATE DEFINITIVO DEL FÚTBOL"**
- Un subtítulo que explique rápido de qué va: **"En 1989 Pelé y Maradona fueron excluidos del Super Balón de Oro. Hoy el mundo decide quién es el verdadero GOAT."**
- Un botón grande y llamativo: "ARMA TU TOP 10"
- Un contador animado que muestre cuántos votos se han registrado (ejemplo: "14,832 votos verificados"), con un efecto de que el número sube
- Debajo del contador, texto pequeño: "Desde 53 países"

### Estilo visual
- Fondo oscuro/negro, elegante, como una noche de gala
- Acentos dorados y metálicos
- Tipografía elegante para títulos (estilo serif moderno o display)
- Tipografía limpia sans-serif para el cuerpo
- Que se sienta premium, lujoso, pero moderno y deportivo — NO anticuado ni corporativo
- Responsive: debe verse genial en móvil y desktop

### Libertad creativa
Tienes libertad total para interpretar el diseño. Puedes agregar efectos visuales, partículas, gradientes, animaciones sutiles, lo que consideres que haga que la página se vea espectacular. Lo único que NO debe pasar es que se vea genérico o de plantilla.

## Tecnología
- React con Tailwind CSS
- Componentes reutilizables
